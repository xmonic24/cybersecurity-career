# Cybersecurity Career

## 🎯 Objective

Build practical, job-ready cybersecurity skills through a structured, hands-on curriculum, with the long-term goal of becoming a professional penetration tester and cybersecurity specialist capable of working in the financial/banking sector.

This repository documents my progression from IT and networking fundamentals through ethical hacking, penetration testing, security engineering, and professional cybersecurity practice.

---

## 🧠 Training Philosophy

This is not a certificate-collection exercise.

The standard for progression is:

**Learn → Practice → Demonstrate → Explain → Document → Test → Advance**

I do not consider a concept mastered simply because I have watched a lesson or completed a room.

If I claim that I can do something, I should be able to:

- Explain how it works
- Demonstrate it practically
- Troubleshoot it when something goes wrong
- Explain why the technique works
- Document what I did
- Apply the knowledge in a new scenario

Weak fundamentals will be revisited before progressing to more advanced material.
