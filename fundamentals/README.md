# IT & Computer Fundamentals

This section documents the foundational knowledge required before progressing into networking, cybersecurity, and ethical hacking.

## Learning Objectives

- Understand how computers represent and process information
- Understand operating-system fundamentals
- Work confidently with Windows and Linux
- Understand filesystems, processes, services, and permissions
- Use the command line effectively
- Understand virtualisation
- Troubleshoot basic computer problems

## Practical Standard

I must be able to demonstrate the concepts practically rather than simply describe them.
