## Key Concepts Learned

### Offensive Security

Offensive security involves thinking like an attacker to identify and validate weaknesses before malicious attackers can exploit them.

### Defensive Security

Defensive security focuses on preventing, detecting, analysing, responding to and recovering from cyber threats.

### Security Operations Centre

A SOC is responsible for monitoring security events, investigating suspicious activity and responding to potential security incidents.

### Penetration Testing

A penetration tester performs authorised security testing to identify vulnerabilities, demonstrate their potential impact and provide evidence and remediation recommendations.
